# Pyrophone logo

The logo combines a lowercase “p” formed from flowing channels with flame-like tips and an outlined lowercase wordmark.

| File | Use |
| --- | --- |
| `pyrophone-logo.svg` | Orange symbol and dark lettering for light backgrounds |
| `pyrophone-logo-dark.svg` | Orange symbol and white lettering for dark backgrounds |
| `pyrophone-logo-black.svg` | Entire logo in near-black |
| `pyrophone-logo-white.svg` | Entire logo in white |
| `pyrophone-mark.svg` | Orange standalone symbol on a square canvas |
| `pyrophone-mark-black.svg` | Near-black standalone symbol on a square canvas |
| `pyrophone-mark-white.svg` | White standalone symbol on a square canvas |

Colors: orange `#FF542E`, near-black `#111111`, white `#FFFFFF`.

All assets have transparent backgrounds and editable vector paths, including the lettering. No font installation is needed. Horizontal logos use a `1380 × 472` viewBox; standalone symbols use `472 × 472`. The viewBoxes include clear space. Keep their aspect ratios and use the supplied variants without stretching or adding effects.

For the repository README, use a 600-pixel display width with the color light and dark variants. Prefer the standalone symbol at 32 pixels or larger.
